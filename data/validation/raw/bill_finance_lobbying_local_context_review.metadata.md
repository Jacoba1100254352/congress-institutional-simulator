# Bill Finance/Lobbying Local Context Review Metadata

Source: curated local-context review over `reports/bill-finance-lobbying-review-queue.csv`.

Scope: the 10 public-law rows whose next lifecycle gate remains bill-specific campaign-finance or lobbying evidence after existing same-policy OpenFEC sponsor context, same-policy LDA issue/bill context, exact LDA bill-identifier review, and LDA activity-text disposition review layers have been applied.

Boundary: this is local bill-finance/lobbying context review only. It records whether current cached same-policy campaign-finance sponsor context and same-policy LDA issue/bill context contain the reviewed current bill ID. It does not show absence of campaign spending, outside-spending targets, lobbying activity, lobbying contacts, sponsor/member targeting, committee-action influence, roll-call influence, legislative-outcome causality, public benefit/welfare, causal capture, or model validation.
