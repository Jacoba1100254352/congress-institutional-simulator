# Raw Validation Inputs

Curated, documented empirical extracts live in this directory. Small public API
adapter fixtures belong in `data/validation/fixtures/` and are intentionally
ignored by the raw validation-readiness check.

Current raw samples:

- `bill_progression.csv`: 180-row Congress.gov 118th Congress offset sample,
  generated by `scripts/validation/build_bill_progression_dataset.py`.
- `bill_progression.metadata.md`: generation parameters and sample-level floor,
  committee-report, and enactment rates.
- `govinfo_billstatus_linkage.csv`: bounded govinfo BILLSTATUS XML
  cross-check for the cached bill-progression rows by congress, bill type, and
  bill number. It records public bill/action metadata only, not a full bill
  census, public-opinion evidence, implementation outcomes, or model
  validation.
- `voteview_rollcalls.csv`: Voteview 118th Congress member-vote sample for
  party-unity and coalition-size checks.
- `voteview_member_context.csv`: Voteview member-metadata context joined to
  the cached roll-call rows by Congress, chamber, and ICPSR member ID. It adds
  Bioguide, party, state/district, and ideal-point metadata only, not
  roll-call-to-bill, public-law, district-opinion, or outcome linkage.
- `voteview_bill_linkage.csv`: Voteview roll-call metadata joined to cached
  vote IDs by Congress, chamber, and roll number. It parses bill numbers and
  flags bounded overlap with cached Congress.gov bill-progression rows only, not
  complete roll-call-to-bill, public-law, district-opinion, or outcome linkage.
- `topic_throughput.csv`: topic-level throughput derived from the bill
  progression sample.
- `sponsor_success.csv`: sponsor proposal-access sample with a bounded
  Congress.gov bill-detail enrichment pass.
- `sponsor_bill_linkage.csv`: bounded sponsor aggregate to public bill-metadata
  linkage by Bioguide sponsor ID. It is not complete sponsor-history, Center for
  Effective Lawmaking, legislative-quality, or model-validation evidence.
- `committee_activity.csv`: committee-report signal derived from bill-action
  histories. This is not a hearing-calendar dataset.
- `lobbying_disclosure.csv`: Senate LDA filing activity sample for spending
  concentration and issue-diversity checks.
- `lobbying_issue_linkage.csv`: deterministic Senate LDA issue-label to local
  Congress.gov policy-area topic crosswalk for the cached lobbying sample. It
  attaches broad issue context only, not bill, sponsor, committee, influence,
  or capture validation.
- `lobbying_bill_mention_searches.csv` and `lobbying_bill_mentions.csv`:
  official LDA filing activity-text search audit for exact current-bill
  identifiers in the bounded public-law candidate set. The current cache records
  exact bill-mention rows only; it is not sponsor/member targeting,
  committee-action influence, roll-call influence, legislative-outcome
  causality, welfare, causal capture, or model-validation evidence.
  The derived `reports/lobbying-bill-action-context.*` report joins those exact
  bill identifiers to cached Congress.gov public-law bill/action, sponsor,
  committee-reported, floor-considered, and enacted-outcome metadata, but it
  remains identifier and legislative metadata context only.
  The derived `reports/lobbying-bill-text-review.*` report classifies bounded
  stored full activity-text support/opposition/position signals for exact-match
  rows while preserving the no-targeting, no-outcome-causality, and
  no-validation boundary.
  The derived `reports/lobbying-bill-disposition-review.*` report prioritizes
  156 of the 484 exact-match rows for manual disposition or target review, but
  remains a source-review queue rather than lobbying-influence evidence.
- `lobbying_bill_manual_disposition_review.csv`: curated source review for the
  4 high-priority rows from `reports/lobbying-bill-disposition-review.*`. The
  derived `reports/lobbying-bill-manual-disposition-review.*` report confirms 3
  current-bill support rows and preserves 1 bill-reference-only row while
  recording no outcome-influence evidence.
  The derived `reports/lobbying-bill-medium-disposition-packets.*` report has no
  separate raw input; it groups the remaining medium-priority disposition rows
  from the generated queue for follow-up review.
- `lobbying_bill_medium_directional_packet_review.csv`: curated packet-level
  source review for the 28 medium-priority support/opposition packets from
  `reports/lobbying-bill-medium-disposition-packets.*`. The derived
  `reports/lobbying-bill-medium-directional-packet-review.*` report confirms 20
  current-bill support packets representing 32 rows, confirms 1 current-bill
  opposition packet, and downgrades 7 packets to other-measure direction or
  monitoring/reference context while recording no outcome-influence evidence.
- `lobbying_bill_medium_position_activity_packet_review.csv`: curated
  packet-level source review for the 74 medium-priority position/activity
  packets from `reports/lobbying-bill-medium-disposition-packets.*`. The
  derived `reports/lobbying-bill-medium-position-activity-packet-review.*`
  report classifies 59 current-bill issue/provision activity packets, 5
  monitoring/analysis packets, 7 all-provisions packets, 2 position-represented
  packets, and 1 current-bill opposition packet found in the position/activity
  queue while recording no outcome-influence evidence.
- `bill_finance_lobbying_local_context_review.csv`: curated local-context
  review for the 10 public-law rows in
  `reports/bill-finance-lobbying-review-queue.*`. The derived
  `reports/bill-finance-lobbying-local-context-review.*` report confirms that
  4 same-policy campaign-finance context rows and 9 same-policy lobbying
  context rows have no current-bill exact match in the current local context,
  while leaving all rows for external target/source expansion and recording no
  outcome-influence evidence.
- `bill_finance_lobbying_external_lda_searches.csv` and
  `bill_finance_lobbying_external_lda_mentions.csv`: official LDA targeted
  current-bill search cache for the same 10-row queue. The derived
  `reports/bill-finance-lobbying-external-search-review.*` report records 30
  compact/dotted term-year searches, 55 exact activity-text bill-reference rows
  across 2 queued bills, and 4 campaign-finance rows marked for FEC/OpenFEC
  candidate, committee, or outside-spending target-scope review.
  The derived
  `reports/bill-finance-lobbying-external-lda-mention-review.*` report groups
  those 55 rows into 19 source-reviewed filing packets, with 0 packets carrying
  explicit support/opposition text, named sponsor/member/committee target,
  committee-action influence, roll-call influence, or legislative-outcome
  causality evidence.
  The derived
  `reports/bill-finance-lobbying-campaign-finance-target-scope-review.*`
  report source-reviews those 4 campaign-finance rows against public
  FEC/OpenFEC target-scope fields, covering 5 context attachments and 2 unique
  public FEC candidate recipients while preserving 0 bill-ID, sponsor-overlap,
  committee-action, or outcome-influence links.
- `campaign_finance.csv`: bounded OpenFEC receipt and independent-expenditure
  sample for concentration and outside-spending proxy checks.
- `campaign_finance_linkage.csv`: public FEC recipient-metadata crosswalk for
  cached campaign-finance recipient IDs. It links to candidate/committee
  metadata only, not bills, sponsors, issues, or causal influence evidence.
- `campaign_finance_member_context.csv`: bounded public FEC candidate metadata
  joined to Voteview member context when name, chamber, state, and district
  evidence agree. It leaves challengers and noncongressional candidates
  unmatched and does not create bill, committee, issue, or influence evidence.
- `campaign_finance_issue_context.csv`: bounded public OpenFEC transaction-label
  issue-context bridge. It maps high-confidence occupation, employer, or
  expenditure-purpose labels to broad local policy-area topics only, not bills,
  committees, legislative outcomes, private-contributor details, or causal
  influence evidence.
- `district_public_opinion.csv`: bounded 2024 Cumulative CES district aggregate
  for support, intensity, turnout, and uninsured-share vulnerability proxies.
- `district_public_opinion_linkage.csv`: Congress.gov member-term and
  public-law bill metadata crosswalk for cached district-opinion rows. It links
  some CES district rows to House-sponsored public-law bills by sponsor district
  only, not bill-topic public support, MRP estimates, affected-group harm, or
  public-benefit evidence.
- `district_public_opinion_policy_context.csv`: bounded sponsor-district
  public-law bill policy-area context rows for cached district-opinion linkage
  rows. It attaches local topic-throughput policy-area counts only, not
  issue-specific bill support, MRP, affected-group harm, representative
  responsiveness, or public-benefit evidence.
- `district_public_opinion_census_denominators.csv`: official Census TIGERweb
  116th congressional-district population, housing-unit, land/water area, and
  centroid denominator rows for queued sponsor districts. It is district-frame
  denominator context only, not ACS policy-specific affected-population detail,
  bill-topic support, MRP, affected-group harm, or public-benefit evidence.
- `district_public_opinion_acs_context.csv`: official ACS 2017-2021 5-year
  broad 116th congressional-district demographic, economic, citizenship,
  language, disability, poverty, employment, internet-access, and veteran
  context rows for queued sponsor districts. It is broad district context only,
  not bill-topic support, MRP/small-area estimates, bill-text-specific
  affected-population definitions, affected-group support/harm, public-benefit,
  or model-validation evidence.
- `court_review.csv`: Supreme Court Database merits-case extract for
  invalidation, signed-opinion, vote-margin, and SCDB legal-authority metadata
  proxy checks.
- `court_law_linkage.csv`: bounded SCDB `lawMinor` U.S.C.-section to Federal
  Register authority-citation overlap cache for cached public-law rows. It is
  not direct case-to-public-law review, lower-court, emergency-order, or
  invalidation evidence.
- `court_public_law_direct_review.csv`: curated manual source-review
  dispositions for post-enactment rows from the court/public-law temporal
  triage queue. The current row classifies an Arellano/Public Law 117-168
  overlap as shared 38 U.S.C. 5110 metadata only, not direct review of that
  public law or bill.
- `rulemaking_implementation.csv`: Federal Register final-rule extract for
  final-to-effective delay and implementation-speed proxies.
- `rulemaking_implementation_linkage.csv`: Federal Register document-metadata
  crosswalk for cached final-rule rows. It links to document, docket, RIN, CFR,
  agency, and Federal Register-exposed Regulations.gov metadata only, not public
  laws, proposed-rule histories, enforcement outcomes, or complete comment
  records.
- `rulemaking_authority_linkage.csv`: Federal Register public-law authority
  search for cached public-law rows. It keeps text-verified rule documents that
  cite the public law and related U.S. Code/CFR metadata only, not exhaustive
  implementation coverage, proposed-rule histories, enforcement outcomes,
  court-review outcomes, welfare, or model validation.
- `rulemaking_history_linkage.csv`: Federal Register proposed-rule history
  search for authority-matched final-rule documents. It keeps proposed-rule
  rows only when they share final-rule RIN or docket identifiers and are not
  later than the final rule. It does not provide complete comment records,
  Unified Agenda stages, enforcement outcomes, appropriations evidence, welfare,
  or model validation.
- `rulemaking_comment_metadata.csv`: Federal Register detail-record refetch for
  authority-matched final rules and matched proposed rules. It records only
  Federal Register-exposed Regulations.gov docket, comment URL, comment-count,
  and comment-close metadata; it does not provide complete comment records,
  commenter identities, comment text, Unified Agenda stages, enforcement
  outcomes, appropriations evidence, welfare, or model validation.
- `rulemaking_comment_records.csv`: bounded Regulations.gov comment-record
  metadata for Federal Register-exposed dockets. It retrieves dockets within the configured threshold,
  records zero-comment dockets as complete no-comment rows, and marks
  high-volume or unknown-count dockets as still incomplete. It does not provide
  comment text, attachments, commenter-identity validation, Unified Agenda
  stages, enforcement outcomes, appropriations evidence, welfare, or model
  validation.
- `law_revision_history.csv`: bounded Congress.gov public-law title and summary
  text flags for amendment, reauthorization, repeal, and sunset language.
- `law_revision_bill_linkage.csv`: bounded Congress.gov bill-detail and
  bill-action metadata for public-law rows. It links public laws to originating
  bill/action metadata only, not codified statutory lineage, implementation
  records, direct court-review records, or U.S. Code target sections.
- `statutory_lineage_source_scan.csv`: official GovInfo public-law text scan
  for the statutory-lineage review queue. It records source URLs, source
  hashes, U.S.C.-reference counts, amendment/repeal/redesignation counts, and
  compact candidate snippets only; it is not OLRC classification, codified
  U.S.C. lineage, target-section text diffs, implementation outcomes,
  court-review proof, welfare, or model-validation evidence.
- `statutory_lineage_no_target_review.csv`: curated source-reviewed
  designation-law no-target dispositions for Public Laws 117-238 and 117-269.
  It records that official GovInfo public-law text and official OLRC
  public-law PDFs expose no U.S.C. references, amendment/repeal/redesignation
  cues, or target-section candidates. It is not target-section text-diff,
  implementation-outcome, court-review, welfare, causal-effect, or
  model-validation evidence.
- `statutory_lineage_olrc_current_scan.csv`: official OLRC current U.S. Code
  page availability scan for structured target-section triage rows. It records
  current section URLs, source hashes, byte counts, and whether the current page
  mentions the queued public law; it is not historical codified-lineage
  evidence, before/after text diffs, implementation outcomes, court-review
  proof, welfare, or model-validation evidence.
- `statutory_lineage_olrc_historical_scan.csv`: official OLRC annual U.S. Code
  page availability scan for year-before-enactment and enactment-year pages for
  current-page candidates that mention the queued public law. It records annual
  edition URLs, source hashes, byte counts, and public-law mention windows; it
  is not codified-lineage evidence, public-law causation, before/after text
  diffs, implementation outcomes, court-review proof, welfare, or
  model-validation evidence.
- `statutory_lineage_olrc_annual_text_diff.csv`: bounded automated cue scan
  over official OLRC annual U.S. Code pages. It records refetched annual page
  hashes, raw-hash comparison flags, normalized section-text signatures,
  bounded first-change windows, post-edition public-law context snippets, and
  manual-review priorities; it is not source-reviewed codified-lineage evidence,
  public-law causation, adjudicated target-section text diffs, implementation
  outcomes, court-review proof, welfare, or model-validation evidence.
- `statutory_lineage_adjudication.csv`: conservative classification of the
  annual OLRC text-diff cue rows into official post-only public-law marker
  evidence. It is codified-lineage marker evidence only, not a source-reviewed
  target-section text diff, public-law causal attribution, effective statutory
  text, implementation outcome, court-review proof, welfare, or
  model-validation evidence.
- `statutory_lineage_target_review_packets.csv`: reviewer packet layer derived
  from the OLRC adjudication and annual text-diff reports. It bundles pre/post
  annual U.S. Code URLs, hashes, normalized section-text signatures,
  post-edition public-law context, and first-change windows for manual review
  only; it is not a source-reviewed target-section diff, public-law causal
  attribution, effective statutory text, implementation outcome, court-review
  proof, welfare, or model-validation evidence.
- `statutory_lineage_target_section_diff_review.csv`: curated official-source
  pilot review of target-section diffs for Public Laws 117-146, 117-166,
  117-167, 117-168, 117-169, 117-174, 117-180, 117-203, 117-219, 117-223,
  117-229, 117-263, and 117-297. It records 75 reviewed dispositions,
  including 73 source-reviewed target-section diff rows and 2 reviewed
  related-section/no-exact-target rows. It is not exclusive public-law causal
  attribution, effective statutory text, implementation outcome, court-review
  proof, welfare, or model-validation evidence.
- `comparative_institutions.csv`: bounded QoG/OWID/V-Dem country-profile
  extract for chamber count, district magnitude, party fragmentation, judicial
  constraints, and legislative-constraints proxies.
- `comparative_institution_linkage.csv`: bounded comparative country-profile to
  simulator scenario-family metadata bridge. It is not observed law-output,
  bicameral-disagreement, country-level institutional-fit, adoption, welfare, or
  model-validation evidence.

The current samples are useful for empirical-bridge checks and rough
agenda-access plausibility. They are not complete congressional censuses,
country-comparative validation targets, or fitted empirical validation.

Run `make raw-source-manifest` from the repository root to regenerate
`reports/raw-source-manifest.csv` and `.md`. The manifest joins
`data/validation/source-registry.csv` to these raw files, metadata notes, row
counts, source hashes, claim boundaries, and transformation scripts.

Run `make build-rulemaking-comment-text-review-raw` when live Regulations.gov
API access is available to refresh the bounded sanitized public comment-detail
review for complete comment-record rows and bounded partial-docket samples.
That raw cache stores text availability, normalized hashes, lengths, attachment
counts, source record status, and coarse cue flags only; it omits the full
comment body and submitter/contact fields. Partial sample rows do not prove
complete docket coverage, and the cache is not a full comment-text,
commenter-identity, sentiment, implementation-outcome, or model-validation
dataset.

Run `make district-public-opinion-ces-source-freshness` when live network access
is available to compare the cached district public-opinion CES metadata to the
current Harvard Dataverse Cumulative CES distribution. That report records
source freshness only; it does not refresh the raw extract or add bill-topic
public-opinion, MRP, or affected-group evidence.
